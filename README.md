# Interactive Orbital Profile

## Project Overview

An innovative, visually engaging personal profile page that uses orbital design to showcase professional information through an interactive, dynamic interface.

## Key Features

- Responsive, animated background
- Concentric orbital rings
- Dynamic information display
- Hover-based interactions
- Smooth, modern design

## Technical Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts (Poppins)

## Page Structure

### Design Elements

- **Gradient Background**: Dynamically animating blue-green gradient
- **Central Name**: Centered name display
- **Orbital Rings**: Three concentric circles representing different professional aspects
- **Information Box**: Slides in from the right with contextual information

### Orbital Rings

1. **Inner Orbit (Skills)**

   - Closest to center
   - Focuses on technical skills and core competencies
   - Fastest rotation

2. **Middle Orbit (Experience)**

   - Represents professional background
   - Moderate rotation speed

3. **Outer Orbit (Education)**
   - Broadest professional context
   - Slowest rotation

## Interaction Mechanics

- Hover over orbital rings to reveal corresponding information
- Dots rotate continuously around each orbit
- Information box dynamically updates based on hover location
- No click required - purely mouse-movement driven

## Responsive Design

- Adapts to different screen sizes
- Mobile-friendly layout adjustments
- Consistent visual experience across devices

## Performance Optimizations

- CSS animations for smooth interactions
- Lightweight JavaScript event handling
- Minimal DOM manipulations

## How to Run

1. Clone the repository
2. Open `index.html` in a modern web browser
3. Hover and explore!

## Customization

Easily modify:

- Orbit sizes in CSS
- Rotation speeds
- Information content in JavaScript

## Dependencies

- No external libraries required
- Google Fonts (Poppins) - loaded via CDN

## Browser Compatibility

- Modern browsers (Chrome, Firefox, Safari, Edge)
- Tested on desktop and mobile
